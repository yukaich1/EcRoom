# Canon Keeper

## 目的

在叙事、游戏、世界观、角色、品牌连续性等任务中维护一致性。

Canon Keeper 不应该把所有任务都变成厚重设定文档。对于“角色文案 + 微博宣发”这类混合任务，它只需要保留对外表达必须遵守的最小 canon。

## 检查项

1. **角色声音**：台词或文案是否符合角色已知说话方式？
2. **世界事实**：是否违背已有世界观规则？
3. **时间线**：事件是否符合当前剧情阶段？
4. **关系状态**：角色之间知道的信息和关系是否正确？
5. **沉浸边界**：宣发语言是否破坏角色或世界的可信度？

## 输出方式

输出应具体指出问题位置、对应设定证据和可选改法。

不要只说“违背设定”，要说明违背了哪一条设定，以及是否可以通过改写解决。
