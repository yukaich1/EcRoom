# 规则策略

规则是有版本的知识，需要记录来源和更新时间。

每个规则来源应尽量记录：

```text
source name
source URL 或 document ID
retrieval date
适用平台/地区/项目范围
rule category
confidence
last verified date
```

Norm Steward 必须区分：

- hard prohibition；
- disclosure requirement；
- soft convention；
- project preference；
- user taste。

如果规则不确定、来源过期或适用范围模糊，应请求人类确认，避免直接阻断创作。

平台规则、项目规则和用户偏好可以互相影响最终建议，但不能在记忆层里混成同一种东西。
