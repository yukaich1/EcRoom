# 种子协作流程

第一版协作流程：

```text
Intent Interpreter
-> Strategist
-> Draft Writer
-> Editor
-> Critic Panel
-> Norm Steward
-> Human Review
-> Memory Curator
-> Harness Evolver
```

Human Review 承担主要学习信号，确认发布只是其中一种结果。

应该捕捉的用户反馈：

- accept；
- reject；
- edit；
- “这个像我”；
- “这个不像我”；
- “保存为项目规则”；
- “保存为个人偏好”。

后续引入 interrupt/resume 能力后，这个流程应该升级成图式 workflow。某些任务可以跳过 Researcher，某些任务需要先进入 Canon Keeper 或 Norm Steward，调度应由 Creative Intent 决定。
