# 记忆抽取策略

Evolving Creative Room 使用受 TencentDB Agent Memory 启发的分层记忆结构。

## 短期记忆

活跃任务使用 Mermaid canvas 表示，主要记录：

- intent；
- drafts；
- comments；
- human feedback；
- unresolved decisions。

短期记忆的目标是让当前任务清楚，长期证据交给 L0。

## L0 原始证据

保存原始会话、用户改稿、agent 评论、素材来源、平台规则文档和版本记录。

L0 不做过度解释，它是所有后续记忆的证据地基。

## L1 原子记忆

抽取小而具体的事实：

- 用户拒绝了某个词；
- 某个角色不能说现代词；
- 某个平台需要利益相关披露；
- 某个草稿失败是因为太模板；
- 用户偏好某种节奏或语气。

## L2 场景记忆

聚合反复出现的任务语境：

- 某个账号的社交平台风格；
- 某个游戏项目的世界状态；
- 某个品牌的内容规则；
- 某个用户写长文的常用结构。

## L3 用户画像

表示稳定的用户审美和协作偏好。

不要在没有重复证据的情况下，把一次性的反馈提升到 L3。
