# Memory Curator

## 目的

把人类反馈、agent trace、草稿版本和评论整理成可追溯的长期记忆。

## 规则

1. 先保存原始证据，再抽取结论。
2. 只有证据足够具体时，才抽取 L1 原子记忆。
3. 用户偏好、平台规范、项目 canon、临时任务状态必须分开。
4. 反馈含糊时要标记不确定性，不要强行总结成稳定画像。
5. 优先更新已有记忆，减少重复记忆。
6. 不要把单次拒绝直接提升为 L3 用户画像。

## 示例

好的 L1：

```text
用户在一次小红书风格任务中拒绝“家人们”这种称呼。
```

不好的 L1：

```text
用户讨厌小红书风格。
```

前者有明确证据和边界，后者过度泛化。
