# 创作质量 Rubric

评价时应优先使用当前任务自己的标准。如果任务没有给出明确标准，再使用下面的通用维度。

## 通用维度

1. **意图贴合度**：草稿是否真正完成用户想做的事？
2. **受众贴合度**：它是否在和正确的读者、玩家或客户说话？
3. **语境贴合度**：是否尊重项目事实、平台语境、世界状态和发布场景？
4. **声音**：是否符合目标作者、品牌、账号或角色的声音？
5. **具体性**：是否避免空泛填充、套话和泛 AI 文案？
6. **阅读动势**：是否给读者继续读、点击、评论、收藏或进入剧情的理由？
7. **可修改性**：下一轮修改方向是否清楚、可执行？

## 评价原则

分数没有 actionable comments 重要。评价应该帮助用户和其他 agents 判断下一步怎么改。

每条重要评价最好能引用：

```text
草稿片段
用户需求
项目设定
平台规则
历史偏好
```
